# Paranoma UI To Scaleform UI (CS:GO-After F2P) 
--
This project uses pre compiled code.pbin(s) -- Kinda requires [csgo-gc](https://github.com/GT-610/csgo-gc) (for not for it to auto run -insecure) and [csgo-paranoma-patcher](https://github.com/excizik/csgo-panorama-patcher) (to patch paranoma.dll) to use or it will auto run -insecure (prob the best to use) 
--
If used, config.txt needs allow_unsigned_panorama	to be 1 ("allow_unsigned_panorama"	"1") and you should rename code.pbin (original) to code.pbin.old (if you want to reuse it) and do the instructions in csgo paranoma patcher and run python pbin.py patch_paranoma or pbin.exe patch_paranoma 
--
Also the Main Menu UI Isn't changed but the in-game screen (scaleform everything)
